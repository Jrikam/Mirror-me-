# Mirror Me

## Description
MirrorMe est une plateforme interactive qui permet aux utilisateurs de découvrir leur personnalité en lien avec différentes catégories (cinéma, musique, littérature, sport), de s’inspirer de figures emblématiques et de se fixer des objectifs personnalisés.

### Prérequis

### Installation

À Faire sur un terminal

Installer Docker:

👉 https://www.docker.com/get-started

Étapes
Cloner le projet :
git clone https://github.com/Jrikam/Mirror-me-
cd Mirror-me

Pour démarrer l'appli
docker-compose up --build

Pour arreter l'appli:
docker-compose up 

## Lancer l’application en local:
http://localhost:8083/index.php
